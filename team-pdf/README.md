TEAM PDF CONVERTER - WINDOWS PORTABLE v2.1

Download the ZIP, right-click it and choose Extract All, then open TeamPDF
and double-click Start Converter.cmd. Keep its window open while converting.
Drop drawings or traces onto the browser page. PDFs go to your Downloads.

No installer, administrator rights, Python installation or LibreOffice
installation is required. The first launch prepares the included engine in
LocalAppData/TeamPDF and checks every supported format before opening the page.
Allow about 2 GB of free space for the ZIP, extracted files and engine cache.
Subsequent launches reuse the checked engine. Company execution policies still
apply; this program does not bypass those policies.

This version has short outer ZIP paths. The large office engine remains in
one office.zip file until the app prepares it itself in a per-user cache.
Do not unpack office.zip manually. Keep all files beside Start Converter.cmd.
You can remove the per-user TeamPDF cache when you no longer use the app.

Formats: .vsd and .vsdx drawings; standard SOR v2 single-trace reports; EXFO
AppReg Format Ex TRC and bidirectional BDR records with uniform group index. Existing PDFs are kept
and new copies receive numbered names. Files are processed locally, with no
external upload. Complex Visio features/fonts may render differently. OTDR
reports do not certify compliance or pass/fail.

If a startup check fails, run Check Converter.cmd. The local Logs folder
contains engine output. No customer drawings are included in the diagnostic
samples. Public Visio examples and their license are included in testassets.
Other component licenses and source locations are listed in COMPONENTS.json.

Release verification is performed by the repository's Windows workflow.
Only a build whose workflow completed successfully should be distributed.
Tests cover extraction, a non-administrator Windows account, the double-click
launcher, VSD/VSDX/SOR/TRC/BDR conversion, default Downloads, browser upload, PDF
structure and rendered output. Passing these samples does not guarantee every
possible drawing or every company execution policy is supported.
